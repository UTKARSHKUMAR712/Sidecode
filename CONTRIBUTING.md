# Contributing to Sidecode

Thank you for your interest in contributing to **Sidecode**! This project is maintained and authored by [utkarshkumar712](https://github.com/UTKARSHKUMAR712).

Whether you are fixing bugs, improving documentation, adding new language support, or enhancing editor capabilities, all contributions are warmly welcomed.

---

## 🛠️ Getting Started

1. **Fork the Repository**:
   Click the "Fork" button at [https://github.com/UTKARSHKUMAR712/Sidecode](https://github.com/UTKARSHKUMAR712/Sidecode).
2. **Clone your fork**:
   ```bash
   git clone https://github.com/<your-username>/Sidecode.git
   cd Sidecode
   ```
3. **Load in Browser**:
   - Open Chrome, Brave, or Edge and navigate to `chrome://extensions/` (or `brave://extensions/`).
   - Enable **Developer mode**.
   - Click **Load unpacked** and select your local `Sidecode` folder.

---

## 📝 Submitting Changes

1. Create a dedicated branch for your feature or bugfix:
   ```bash
   git checkout -b feature/awesome-feature
   ```
2. Test your changes thoroughly across:
   - File creation, editing, and saving.
   - Cloud compilation (`☁ Cloud Terminal`).
   - Local execution (`⚡ Local PC Terminal`).
   - Browser sandbox (`💻 Browser Sandbox`).
3. Commit with clear, descriptive commit messages:
   ```bash
   git commit -m "feat(explorer): add custom icon for swift files"
   ```
4. Push to your fork and submit a Pull Request to `UTKARSHKUMAR712/Sidecode` on `main`.

---
