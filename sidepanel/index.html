Input Typing Rules

Sidecode uses Strict Typing Rules to validate your input before sending it to the compiler:

  • Multiple Inputs: Use a new line (Enter key) to separate different inputs (e.g., if you have two input() calls, put the first value on line 1, and the second on line 2).
  • Numbers: Type normally (e.g., 10, -3.14).
  • Booleans: Type true, false, or null.
  • Strings: MUST be wrapped in double quotes (e.g., "Hello"). To include a quote inside a string, escape it (e.g., "Say \"Hi\"").
  • Raw Strings: You can also use backticks (e.g., `Say "Hi" to me`). Everything inside backticks is passed exactly as-is without needing to escape anything!
  • Arrays: Wrap comma-separated values in brackets (e.g., [1, 2, "Alice"]). Arrays are automatically flattened into space-separated values for the compiler.
