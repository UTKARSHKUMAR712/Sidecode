Input Typing Rules

When Strict Typing Rules is enabled, Sidecode validates your input before sending it to the compiler:

  • Numbers: Type normally (e.g., 10, -3.14).
  • Booleans: Type true, false, or null.
  • Strings: MUST be wrapped in double quotes (e.g., "Hello"). To include a quote inside a string, escape it (e.g., "Say \"Hi\"").
  • Arrays: Wrap comma-separated values in brackets (e.g., [1, 2, "Alice"]). Arrays are automatically flattened into space-separated values for the compiler.

If you uncheck Strict Mode, Sidecode acts like a raw Linux terminal (what you type is exactly what the program receives without any parsing).
